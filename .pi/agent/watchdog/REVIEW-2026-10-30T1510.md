# Watchdog review — 2026-10-30T15:10Z (planner + project context)

## What changed since the last review

Routing moved from "one classifier call over the inventory" to: raw-prompt classification (floor) +
planner pass (project-aware workstreams) + per-workstream classification, merged and deduped.

## Claims vs evidence

| Claim | Evidence |
|---|---|
| Planner reads project context | Rust fixture: `code review this` → rust-async-patterns + rust-refactoring; Next.js fixture → vercel-react-best-practices |
| Context as a JSON field is useless | 5 variants measured, rust stayed at 0.015–0.06 vs 0.246 in text |
| Multi-part prompts get multiple hints | 6, 5, 5, 3 hints on audit/migration/review/rename prompts |
| Off-project prompts stay silent | `what is 2+2` silent in a Rust repo after the bleed fix |
| Tests pass | 26 pass, 0 fail |
| Router's latency share | planner 1.1 s (`think: false`) + classifier 0.9 s/workstream; environment startup is 18–20 s with all packages |

## Findings

1. **High (fixed) — brief bleed.** Appending the project brief to the classifier text made `2+2` in a
   Rust repo yield Rust hints. Context now reaches the classifier only through planner workstreams,
   and non-project tasks are answered `none` by the planner.
2. **High (fixed) — planner as replacement broke two cases.** "explain the architecture: who calls
   this module" went silent (planner answered `none` for a question about the codebase) and
   "make it better" went silent (rewritten workstream scored below the floor). Raw classification is
   now always run and merged; the planner only adds.
3. **Medium (open) — tail noise.** Workstream picks add low-value lines: `rust-async-patterns` on a
   database-migration prompt, `engineering-git-workflow-master` on a code review. The 6-hint cap and
   0.15×floor keep them ranked last, but they are still shown.
4. **Low (open) — latency is startup-dominated.** 4–11 s to first token, of which ~2 s is this router
   and 18–20 s is the rest of the environment (measured with the router inert).

## Not verified

- Whether 6 hints read as guidance or as a menu in real use.
- Monorepo / unusual-manifest detection (`project: unknown` path).
- The permission system under the new planner call (it uses the session model through Pi's registry,
  no new file or network surface beyond Ollama, which the session already uses).
