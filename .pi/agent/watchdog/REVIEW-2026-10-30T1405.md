## Findings

1. **High (fixed) — the first two designs were wrong, and the evidence came late.** 157 hand-written
   keywords missed "review" and had zero overlap with "make this query faster". An IDF shortlist over
   descriptions also failed ("the build fails with a stack trace" surfaced nothing relevant). Both were
   replaced by one decision model over the full inventory. Lesson recorded in memory.
2. **High (fixed) — my first gate was miscalibrated.** 0.45/3× was derived from a 5-option toy test; with
   119 options the mass spreads (top 0.245 on a real prompt) and the router went silent on 9 of 11
   probes. Recalibrated to 0.2/1.8× against 11 measured distributions.
3. **Medium — an apparent hang was actually success.** Two `pi -p` runs exceeded a 200 s timeout; the
   event log showed 7 turns and 15 tool calls — the model was following the hint. Verified by counting
   events, not by trusting the timeout.
4. **Info — `models.json` cannot declare classifiers** (chat-only), so the wiring lives in
   `clef.ts` via `registerProvider`. Documented in README and memory so this is not rediscovered.
5. **Info — 74 of 78 agents have never been used**, which is the actual problem this feature exists to
   move.
